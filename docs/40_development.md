# 開発の進め方

## 開発フローとルール
- **TDD (Test-Driven Development)**: 
  - 新機能の実装時は、まずテストを書き、失敗を確認してから実装を進めてください。
  - バグ修正時は、必ず問題を再現するテストケースを先に作成してください。
- **コード品質**:
  - Surgical edits (最小限かつ正確な修正) を心がけてください。
  - 既存の命名規則（キャメルケース）とTypeScriptの型定義を厳守してください。

## 主要なコマンド
- テスト実行: `bun test`
- 特定のテスト実行: `bun test tests/metrics/acd.test.ts`
